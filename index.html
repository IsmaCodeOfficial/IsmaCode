Ejemplos listos

Funciones útiles

  • largo(x) cuenta letras o elementos
  • azar(a, b) número aleatorio entero
  • rango(a, b) crea una lista de números
  • elegir(lista) elige un elemento al azar
  • ordenar(lista) ordena sin tocar la original
  • promedio(lista) calcula la media
  • contiene(a, b) comprueba si algo está dentro
  • reemplazar(t, a, b) cambia texto
  • pantalla(640, 360) prepara el lienzo
  • rectangulo(x, y, a, h) pinta formas
  • choca(...) detecta colisiones
  • limitar(x, min, max) controla movimiento
  • tecla("derecha") lee el teclado
  • joystick(tam) pad táctil → .dx .dy .arriba...
  • saltar(tam) botón acción del pad
  • fotograma(60) anima a 60 FPS

Reglas simples

  • Los bloques terminan con fin.
  • : y dos puntos abren bloques.
  • ,hola, también es texto.
  • Variables como año y niño funcionan.
  • Las listas usan corchetes: ["pan", "agua"].
  • Los textos van entre comillas.
